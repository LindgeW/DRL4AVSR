# DRL4AVSR
Official Implementation of "Decoupled Representation Learning for Robust Audio-visual Speech Recognition"

### Requirements
- torch == 2.5.1+cu124
- torchaudio == 2.5.1+cu124
- torchvision == 0.20.1+cu124
- transformers == 4.52.4
- av == 15.1.0
- librosa == 0.11.0
- opencv-python == 4.11.0
- jiwer == 4.0.0
